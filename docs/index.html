PINTRACKER · UNITREE G1

PinTracker：一个跟得更稳的 G1 全身动作跟踪器

代码和权重：github.com/quantumiracle/PinTracker

给人形机器人一段参考动作，让它在物理仿真里稳稳地跟着做完，是动作生成、遥操作和模仿学习的共同底座。PinTracker 是我们为 Unitree G1（29 自由度）训练的全身动作跟踪器：输入参考动作，以 50 Hz 输出关节目标位置。在它从没见过的 AMASS 动捕数据上，它把 95.8% 的片段完整跟到了底，NVIDIA 公开的 SONIC 是 92.2%；训练只用了约 16 个 GPU 小时。

结果

在 MuJoCo 里评测：每条片段从第一帧开始播放一遍，不加随机化和噪声。AMASS 和 LAFAN1 都不在 PinTracker 的训练数据里，SONIC 也没有在它们上训练过。SONIC 用的是 NVIDIA 公开发布的权重，跑在同一个仿真里。

PinTracker 更少摔倒：1,202 条里有 53 条是它跟到底而 SONIC 摔倒，反过来只有 10 条。SONIC 的姿态误差更小，在两者都跟住的片段上它的身体姿态更贴近参考。AMASS 测试集是从 TWIST 重定向好的 AMASS 动作里按固定种子随机抽的 1,602 条，这里统计 SONIC 跑完的 1,202 条；它不是 SONIC 论文里的那个子集，数字只能和论文大致对照。LAFAN1 的 40 条都是 2–4.5 分钟的长片段，两者都会在摔倒后爬起这类动作上失败，跟到底的条数基本持平。

怎么做的

PinTracker 沿用 SuperMimic 的基于模型的强化学习配方：一边在仿真里收集经验，一边训练一个预测机器人动力学的世界模型，再在世界模型的想象轨迹里优化策略。策略是一个 9,000 万参数的编码器-解码器网络，输入未来 10 帧参考动作和最近 10 帧本体感知，输出相对下一帧参考姿态的关节修正量。训练数据是约 1,600 小时从网络视频中提取、再重定向到 G1 的人体动作；训练时随机化地面摩擦、关节零偏和躯干质心，并加入观测和动作噪声。

数据量和模型大小都有用，数据量的作用更大。只用 100 小时动作时，把策略加宽 10 倍（900 万 → 9,000 万参数），AMASS 上完整跟到底的比例从 92.2% 升到 93.7%；同样的大模型把训练动作扩到约 1,600 小时，又升到 95.8%。

试一试

需要 Linux 和 NVIDIA GPU。权重在 GitHub Release 里，接口和动作格式见仓库 README。

git clone https://github.com/quantumiracle/PinTracker.git && cd PinTracker
pip install -e .
curl -L -o pintracker.pt https://github.com/quantumiracle/PinTracker/releases/download/v0.1.0/pintracker_g1_big_full.pt

python scripts/convert_motion.py my_motions/*.pkl --out clips/      # 你的动作 → 50 Hz 片段
python scripts/track.py --ckpt pintracker.pt --clips clips/ --videos videos/

局限

  • 目前只在仿真中验证，还没有上真机。
  • 摔倒后爬起、躺地这类动作还跟不住。
  • 姿态精度略逊于 SONIC（MPJPE 35 mm 对 29 mm）。
  • 策略较大（9,000 万参数），部署时需要考虑推理开销。
评测动作来自 AMASS（经 TWIST 重定向）和 LAFAN1；样例视频是 AMASS 动作的仿真渲染，仅用于展示。SONIC 为 NVIDIA 发布的 GEAR-SONIC 权重（NVIDIA Open Model License），仅用于对比，不包含在本项目中。
