PINTRACKER · UNITREE G1

PinTracker: a G1 whole-body tracker that stays on its feet

Code and weights: github.com/quantumiracle/PinTracker · 中文

Making a humanoid follow a reference motion through to the end in physics simulation is the shared foundation of motion generation, teleoperation and imitation learning. PinTracker is a whole-body motion tracker for the Unitree G1 (29 DoF): it takes a reference motion and outputs joint position targets at 50 Hz. On AMASS motion capture it has never seen, it tracks 96.2% of clips all the way to the end, against 92.2% for NVIDIA's released SONIC, with a policy of only 9 million parameters trained in about 12 GPU-hours. A 10× larger version, PinTracker-L, performs on par.

PinTracker falls less: on 57 of the 1,202 clips PinTracker-S tracks to the end where SONIC falls, and only 9 the other way round (53 vs 10 for PinTracker-L). SONIC has the lower pose error: on clips both complete, its body pose stays closer to the reference. The AMASS test set is 1,602 clips drawn at random with a fixed seed from TWIST's retargeted AMASS, counted here on the 1,202 clips SONIC finished; it is not the subset used in the SONIC paper, so the numbers compare with the paper only roughly.

Try it

Needs Linux and an NVIDIA GPU. The PinTracker-S weights come with the repository (36 MB); PinTracker-L is in the GitHub release. The interface and motion format are in the repository README.

git clone https://github.com/quantumiracle/PinTracker.git && cd PinTracker
pip install -e .

python scripts/convert_motion.py my_motions/*.pkl --out clips/      # your motions -> 50 Hz clips
python scripts/track.py --ckpt weights/pintracker_g1_small_full.pt --clips clips/ --videos videos/

Limitations

  • Validated in simulation only; not yet on a real robot.
  • Falls and get-ups, and motions lying on the floor, are not tracked.
  • Pose accuracy is slightly below SONIC's (MPJPE 35 mm vs 29 mm).
  • PinTracker-L is large (90 million parameters, 360 MB); PinTracker-S is usually enough.
Evaluation motions are from AMASS (retargeted by TWIST); the sample videos are simulator renders of AMASS motions, shown for illustration. SONIC is NVIDIA's released GEAR-SONIC (NVIDIA Open Model License), used for comparison only and not included in this project.
