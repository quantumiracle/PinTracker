PinTracker：G1 全身动作跟踪器

输入一段参考动作（关节角和根节点位姿随时间的变化），PinTracker 以 50 Hz 输出关节目标位置，让仿真中的 G1 跟着做。它用 SuperMimic 的基于模型的训练方法，在 Movens-5M 的 1,592 小时参考动作上训练。在两个它没见过的测试集上，它跟到底的比例与 NVIDIA 的 SONIC 相当或更高。内部研究版本：权重和本页的样例视频都不得对外分发。

怎么用

安装

需要 Linux 和 NVIDIA GPU（mjlab 用 MuJoCo Warp 在 GPU 上仿真）。权重在仓库的 v0.1.0 Release 附件里（360 MB）。

git clone git@github.com:quantumiracle/PinTracker.git && cd PinTracker
pip install -e .
scripts/download_checkpoint.sh   # 需要 gh auth login，且有该私有仓库的权限

跟踪自己的动作

# 1. 动作转成 50 Hz 的片段（支持 GMR / TWIST / Movens 格式的 pkl，23 或 29 自由度的 G1）
python scripts/convert_motion.py motions/*.pkl --out clips/
# 2. 在仿真里跟踪，输出每条的指标和视频（实体是机器人，蓝色半透明是参考）
python scripts/track.py --ckpt checkpoints/pintracker_g1_big_full.pt --clips clips/ --videos out/videos
from pintracker import load_policy
from pintracker.track import track, summarize, render

policy = load_policy("checkpoints/pintracker_g1_big_full.pt")
env, rows, rollout = track(policy, ["clips/walk.npz", "clips/dance.npz"])
print(summarize(rows))          # 成功率、回报、MPJPE …
render(env, rollout, "out/videos")

动作格式

每条片段一个 .npz，50 Hz、float32：root_pos（T×3，骨盆位置，m，z 朝上）、root_quat（T×4，wxyz）、root_v 和 root_w（T×3，世界系）、joint_pos 和 joint_vel（T×29，按 mjlab G1 的关节顺序：左腿 6、右腿 6、腰 3、左臂 7、右臂 7）、fps=50。转换脚本会从任意帧率重采样并算出速度，23 自由度的动作手腕补 0。

策略接口（50 Hz 调用）

hist (B, 10, 93)最近 10 帧本体感知，最新的在最后：关节角减默认姿态（29）、关节速度（29）、骨盆系角速度（3）、骨盆系重力方向（3）、上一步动作（29）。
goal (B, 670)未来 10 帧参考（t+1 … t+10），每帧 67 维：参考关节角（29）、参考关节速度 / 5（29）、参考躯干位置在机器人躯干系下的坐标（3）、参考躯干相对机器人躯干的朝向（6 维旋转）。
action (B, 29)归一化动作：关节目标 = 默认姿态 + 动作尺度 × action。默认姿态和动作尺度存在检查点里（policy.ref_q0、policy.ref_scale），PD 增益用 mjlab 的 G1 配置。

goal 里有参考躯干相对机器人躯干的位置，所以它会纠正全局漂移；上真机时需要躯干的全局位姿估计（动捕或状态估计）。每个量的精确定义见 pintracker/task.py。

模型和训练

  • 策略：目标编码器 670 → 7680 → 3840 → 1920 → 960 → 32（tanh），解码器 32 + 10×93 → 7680 → 3840 → 1920 → 960 → 29，ELU，共 90M 参数；输出是对下一帧参考姿态的残差。检查点存的是权重的 EMA 平均（衰减 0.995），也就是评测用的版本。
  • 训练方法：SuperMimic 的基于模型的配方（世界模型 3×3584，32 步想象，Muon 优化器），训练时随机化脚底摩擦、关节零偏和躯干质心，并加观测噪声和动作噪声。
  • 三个阶段：先在 100 小时的 Movens 子集上训 9,200 次（8×H100）；再在全量 1,592 小时上训 2,000 次（8×H200，32,768 个并行环境，学习率 4e-4）；最后在全量上再训 1,000 次（策略先冻结 300 次，再用 500 次把学习率预热到 1e-4）。合计约 16 GPU·时。

局限

  • 只在仿真里验证过，没上过真机。
  • 模型大：90M 参数，float32 权重 360 MB。
  • LAFAN1 的 6 条摔倒后爬起的片段全部失败（躺在地上的动作跟不住）；其余失败都发生在几分钟长的走路、格斗、舞蹈片段的后段（1–4 分钟之后）。
  • 姿态精度比 SONIC 差一点：AMASS 上的 MPJPE 是 35 mm，SONIC 是 29 mm。
权重在 Movens-5M（许可证 "other"，未授予再分发权）上训练，仅限内部研究使用。评测数据不在仓库里：AMASS（经 TWIST 重定向，仅限非商业研究、不得再分发）、LAFAN1（Ubisoft，CC BY-NC-ND 4.0）。本页样例视频是这些动作的仿真渲染，请勿外传。SONIC 仅用于对比，权重为 NVIDIA Open Model License，不在仓库里。
